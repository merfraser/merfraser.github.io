Visualizing the palmer penguins data with Python

Author

Meredith Fraser

Published

September 23, 2026

In this blog, we are going to examine the palmer penguins dataset (Gorman et al., 2014; Palmer Penguins Dataset, 2014) using python. Data were collected and made available by Dr. Kristen Gorman and the Palmer Station, Antarctica LTER.

I am interested in which penguin species tends to be the largest (in both flipper length and body mass), and investigating if there is any visible relationship between penguin flipper length (cm) and body mass (g). This is an initial examination/visualization if measured flipper length is a viable praxis for body mass (not fitting any models in this example).

I will first start by organizing or ‘tidying’ the data for our question, including dropping all NAs from the dataset, converting flipper length (measured in mm) (more readable), and selecting only the columns I am interested in.

# Import the required libraries
import pandas as pd
from palmerpenguins import load_penguins
import altair as alt

# Load the penguins dataset
penguins = load_penguins()

# Clean up the dataset and prep for summarizing and visualizing
## Drop `NAs` from the flipper_length_mm and body_mass_mg columns (the variables we are interested in) 
penguins_clean = penguins.dropna(subset=['flipper_length_mm','body_mass_g'])
## Create a new column: flipper_length_cm (converting mm to cm)
penguins_clean['flipper_length_cm'] = penguins_clean['flipper_length_mm']/10
## Index only the required columns for our question (spcies, flipper_length_cm, body_mass_g)
penguins_clean = penguins_clean[['species','flipper_length_cm','body_mass_g']]

# Print the head of the tidy penguins dataset

Now we can group the tidied data by species and produce some summary statistics of our two variables of interest for each of the penguin species.

penguins_summary = (
    penguins_clean
    .groupby(['species'])
    .aggregate(["mean","std"])
    .reset_index()
)

Interesting! From the summary table above, Gentoo penguins, on average, tend to have the longest flippers and greatest body mass compared to Adelie and Chinstrap penguins.

Now let’s go ahead and plot flipper length (cm) by body mass (g) to do an initial check if there is any visible relationship between flipper length and body mass.

alt.Chart(penguins_clean).mark_point().encode(
    x=alt.X('flipper_length_cm', 
        scale=alt.Scale(domain=[16, 24]),      
        axis=alt.Axis(title='Flipper length (cm)')    
    ),
    y=alt.Y('body_mass_g', 
        scale=alt.Scale(domain=[2000,7000]),      
        axis=alt.Axis(title='Body mass (g)')    
    )
)

In Figure 1, when we plot flipper length (cm) by body mass (g), colour-coded by species, we can see a clear relationship between the two variables where the points are organized in what appears to be a positive linear trend.
